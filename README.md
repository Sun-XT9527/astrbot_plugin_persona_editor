# 人格进化（仅人设） v0.3.0

把对话中的明确长期反馈整理成人格中的互动习惯，经效果比较和人工审核后，写入 AstrBot「人格设定 → 系统提示词」。

## 如何运作

1. 私聊回复发送后，用本地规则识别“以后少说教”“不要每次结尾都追问”等反馈并保存在本地队列，白天不调用分析模型；普通闲聊、命令和日程不进入队列。
2. 仅管理员与 `feedback_users` 中的用户能触发；只允许配置中的自定义人格。群聊和主动消息不触发。
3. 每天北京时间 23:00 集中分析一次，用反馈来源会话的模型（或指定模型）读取当前人格、已有互动习惯和收集的原话，生成最多 8 条简短习惯。原核心人设逐字保留；用户资料、事件与安排不得写入。
4. 运行 3 组修改前后回复对照：短回复指代、纠正错误、本次反馈对应的虚构案例。审查员对随机排列的两个版本评分，并审查事实混入和核心人设冲突。
5. 所有案例不退步、总分严格提高，才保存为待审建议；同分、不通过、模型失败或超时均保留原人设。模型评分是辅助证据，不保证实际体验一定提升。
6. 在后台「人格进化」查看反馈依据、文字差异和对照回复，点击「采用并写入人格设定」。也可拒绝或回退。

完整分析最多 8 次模型调用：反思 1 次、对照回复 6 次、审查 1 次。最多两路并发，单次调用超时 50 秒，无自动重试。未形成有效反馈会提前停止。每个人格北京时间每天最多分析一次，手动提交也只入队，不会提前分析。无新反馈不调用模型；有待审建议时保留反馈至之后处理。一次最多汇总 1500 字，其余留待下次。

反馈、当天分析记录和去重状态会持久化，重载不会多跑一次。采用独立每日任务，暂停/重载时停止；不向 AstrBot「未来任务」增加通用唤醒任务。电脑需在 23:00 在线运行 AstrBot：延迟不足 5 分钟可继续，错过后保留反馈到次日 23:00，不在第二天早上补跑。分析中断时反馈返回队列，但当天不重试。

## 写到哪里

只通过 AstrBot PersonaManager 更新现有人格的 `system_prompt` 字段。后台原来的「笨蛋大肥鱼」会显示末尾新增的「对话反馈形成的互动习惯」区。

原身份、角色形象、性格、工具列表、技能、预设对话与其他字段保留。习惯区是完整替换和合并，不是每次无限追加。若人工把文字加在学习区之后，插件会要求先整理结构，避免覆盖人工改动。

本插件没有记忆检索、好感度、情绪模拟、主动消息或普通模型请求注入。回复后只收集明确反馈，唯一的定时工作是每日人格分析；停用或重载会取消未完成分析。不能修复主动消息的睡眠唤醒问题。

## 配置

| 配置 | 默认 | 作用 |
|---|---|---|
| 允许提出和应用人格修改 | 开 | 总开关，关闭后禁止新分析和人设写入 |
| 允许修改的人格名称 | 笨蛋大肥鱼 | 自定义人格白名单，不允许默认人格 |
| 从私聊反馈自动提出建议 | 开 | 回复发送后收集明确反馈，等每日时间集中分析；仍需审核 |
| 允许提供人格反馈的用户 ID | 空 | 管理员以外允许提出建议的用户；不增加管理权限 |
| 反思与对照模型 | 空 | 跟随收集反馈的会话模型；也可填写已配置的聊天模型 ID |
| 每日分析时间（北京时间） | 23:00 | 每日最多一次；修改时间后重载插件生效 |

Dashboard 手动反馈使用所选模型，留空时跟随默认会话模型。后台登录用户可审核；QQ 审核命令使用 AstrBot 原有管理员权限。

## 审核与回退

- `/pe review`：待审列表。
- `/pe review 编号`：修改依据和逐行差异。
- `/pe approve 编号`：写入该项建议。
- `/pe reject 编号`：拒绝，原人设不变。
- `/pe rollback 编号`：恢复该项修改前全文。

每次写入前保存原文和哈希。人设后来被其他操作修改时，旧建议和回退均拒绝覆盖。中断可使用同一编号重试核对。审核记录在本插件数据目录 `persona_reviews.json`，不删除旧版本。较早 v0.1.0 未评估建议不能直接批准。

## 安装与替换

先停用 `astrbot_plugin_self_evolution` 并暂停其 `SelfEvolution_*` 任务，保留旧数据。新旧插件提供同名 `evolve_persona` 工具，不能同时启用。将本目录安装到 AstrBot 的 `data/plugins/astrbot_plugin_persona_editor` 并正常加载。管理页在「插件 → 人格进化 → 页面」，或侧边栏扩展功能中。

确保人格工具中选中 `evolve_persona`。旧版人设中的完整新人设参数仍兼容，但插件不会直接信任或采用工具传入的全文，而是以当前用户原话独立分析。可将旧版优化说明更新为“明确反馈时调用工具提出建议，分析完成且管理员批准后生效”。

## 验证

测试覆盖：北京时间 23:00 的时区转换、不提前运行、过时跳过、每日上限、反馈持久化与去重、反馈批量长度、分析中断恢复、任务停用，以及核心原文保留、对照比较、私聊用户限制、仅写人设字段、旧建议保护、批准与回退。

运行：`python -m unittest discover -s astrbot_plugin_persona_editor/tests -t . -v`（从父目录）。模型真实调用和安装状态应以诊断目录的本次交付记录为准，测试通过不代表真实 QQ 行为已观察完成。
